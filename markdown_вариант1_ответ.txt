#### 1. Что требует ТЗ

Функция can_buy(age):
- принимает возраст (целое число);
- возвращает True, если возраст 18 и больше;
- возвращает False, если меньше 18.

#### 2. Что код делает на самом деле

Проверяет только age > 18. Если больше 18 — возвращает строку «да». Если 18 или меньше — ничего не возвращает.

#### 3. Несоответствия

1. В ТЗ «18 и больше» (>= 18), в коде > 18. В 18 лет не пройдёт.
2. Нужны True/False, возвращается текст «да».
3. Нет return False для возраста меньше 18.
4. Нет проверки, что age — число.

#### 4. Вердикт

Отклонить

#### 5. Что исправить

Писать age >= 18, возвращать True/False, добавить ветку для возраста меньше 18.

---

### 3. Исправленный код

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```
