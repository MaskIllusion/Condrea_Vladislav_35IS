#### 1. Что требует ТЗ

Функция check_pin(raw):
- на вход строка из ровно 4 цифр;
- буквы и знаки запрещены;
- если PIN верный — вернуть "ok";
- если нет — вернуть "bad";
- ошибки ловить через try/except;
- в finally печатать "пин проверен".

#### 2. Что код делает на самом деле

Проверяет длину: если >= 4 — возвращает "ok", иначе "bad". В except всегда возвращает "ok". В finally печатает "пин проверен" и всегда возвращает "ok" (перезаписывает результат).

#### 3. Несоответствия

1. В ТЗ нужно ровно 4 цифры, в коде проверяется >= 4. Пин из 5 цифр тоже пройдёт.
2. Нет проверки, что все символы — цифры. Буквы и знаки пройдут.
3. В except возвращается "ok" — это неправильно. При ошибке должно быть "bad".
4. В finally есть return "ok", который перезаписывает возвращаемое значение из try/except. Даже если в try должно вернуться "bad", в finally вернётся "ok".
5. Нет приведения к строке (если передадут число — может упасть).

#### 4. Вердикт

Отклонить

#### 5. Что исправить

1. Проверять длину строго == 4.
2. Проверять, что все символы — цифры (через isdigit()).
3. В except возвращать "bad".
4. Убрать return из finally, оставить только print.
5. Добавить приведение к строке.

### 3. Исправленный код

```python
def check_pin(raw):
    try:
        pin = str(raw)
        
        if len(pin) == 4 and pin.isdigit():
            return "ok"
        else:
            return "bad"
            
    except:
        return "bad"
        
    finally:
        print("пин проверен")
```
