### 2. Пояснение к проверкам

- **5 5 0 → 10** — сумма 5 + 5 = 10, ноль завершает работу.
- **Сразу 0 → 0** — ноль завершает программу, сумма остаётся 0.
- **Ноль не прибавляется к сумме** — 0 не влияет на итог.
- **абв не роняет программу** — при вводе текста программа не падает, выводит ошибку.
- **После абв цикл продолжается** — после неверного ввода программа не завершается.
- **Минус тоже в копилке** — отрицательные числа вычитаются из суммы.

---

### 3. Пример кода (исправленный модуль)

```python
total = 0
while True:
    try:
        num = int(input("Монета: "))
        if num == 0:
            break
        total += num
    except ValueError:
        print("Не число")
        continue

print("Итог:", total)
```
