#### 1. Что требует ТЗ

Функция is_pass(score):
- принимает баллы (число);
- возвращает True, если баллов 60 и больше;
- возвращает False, если меньше 60.

#### 2. Что код делает на самом деле

Проверяет условие score >= 60. Если баллов 60 и больше — выводит текст «зачёт» на экран. Если меньше 60 — ничего не делает.

#### 3. Несоответствия

1. В ТЗ нужно вернуть True/False, а код выводит текст «зачёт».
2. Нет return False для баллов меньше 60.
3. Нет return True для баллов 60 и больше.
4. Нет проверки, что score — число.

#### 4. Вердикт

Отклонить

#### 5. Что исправить

Заменить print("зачёт") на return True. Добавить return False для всех остальных случаев.

---

### 3. Исправленный код

```python
def is_pass(score):
    if score >= 60:
        return True
    return False
