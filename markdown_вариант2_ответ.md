#### 1. Что требует ТЗ

Функция is_strong(password):
- принимает строку пароля;
- возвращает True, если длина пароля не меньше 8 символов;
- возвращает False, если короче 8.

#### 2. Что код делает на самом деле

Проверяет только len(password) > 8. Если длина больше 8 — возвращает True. Если 8 или меньше — ничего не возвращает.

#### 3. Несоответствия

1. В ТЗ «не меньше 8» (>= 8), в коде > 8. Пароль из 8 символов не пройдёт.
2. Нет return False для паролей короче 8.
3. Нет проверки, что password — строка.

#### 4. Вердикт

Отклонить

#### 5. Что исправить

Поменять > на >=, добавить return False, добавить проверку типа.

---

### 3. Исправленный код

```python
def is_strong(password):
    if len(password) >= 8:
        return True
    return False
```
