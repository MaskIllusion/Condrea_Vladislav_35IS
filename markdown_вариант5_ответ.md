#### 1. Что требует ТЗ

Функция need_jacket(temp):
- принимает температуру воздуха;
- возвращает True, если температура ниже 10;
- возвращает False, если 10 и выше.

#### 2. Что код делает на самом деле

Проверяет условие temp < 10. Если температура ниже 10 — возвращает False. Если 10 и выше — ничего не возвращает.

#### 3. Несоответствия

1. В ТЗ нужно вернуть True при температуре ниже 10, а код возвращает False.
2. Нет return False для температуры 10 и выше.
3. Нет проверки, что temp — число.

#### 4. Вердикт

Отклонить

#### 5. Что исправить

Поменять return False на return True. Добавить return False для второго случая.

---

### 3. Исправленный код

```python
def need_jacket(temp):
    if temp < 10:
        return True
    return False
```
